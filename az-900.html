AZ-900: Azure Fundamentals

Microsoft's entry-level certification covering core Azure cloud concepts and services

Overview

AZ-900 (Microsoft Azure Fundamentals) is Microsoft's entry-level certification validating foundational knowledge of cloud concepts, core Azure services, pricing, and governance — designed for anyone starting to work with Azure regardless of technical role. In 2026, AZ-900 remains the standard first step in the Azure certification path, commonly required or recommended before pursuing role-based certifications like AZ-104 (Administrator) or AZ-104's more advanced counterparts.

Key Value: AZ-900 gives IT staff, and even non-technical stakeholders working alongside cloud teams, a shared vocabulary and foundational understanding of Azure — a low-cost, low-barrier way to raise baseline cloud literacy across an organization.

Core Components

Exam Coverage

  • Cloud concepts (economies of scale, shared responsibility)
  • Core Azure services (compute, networking, storage)
  • Azure pricing, SLAs & lifecycle

Target Audience

  • Non-technical stakeholders needing cloud literacy
  • IT staff beginning their Azure certification path
  • Sales & pre-sales roles supporting Azure-based solutions

Certification Path

  • Prerequisite/recommended step before AZ-104 (Administrator)
  • Foundation for role-based Azure certification tracks
  • No technical prerequisites required

Best Practices

  • Use AZ-900 as a low-barrier way to raise cloud literacy broadly across teams
  • Treat it as a foundation step before pursuing role-based Azure certifications
  • Encourage non-technical stakeholders working with cloud teams to pursue it
  • Keep certification knowledge current as Azure services evolve
  • Pair certification with hands-on Azure portal experience for practical grounding

IT Director Responsibilities

  • Sponsor AZ-900 as a baseline cloud literacy certification across relevant teams
  • Use it as a prerequisite step in broader Azure certification pathways
  • Track certification coverage as part of cloud skills inventory
  • Budget for certification renewal & continuing education
