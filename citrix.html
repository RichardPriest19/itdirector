Citrix

Application and desktop virtualisation – delivering apps and full desktops securely to any device

Overview

Citrix is best known for virtual apps and desktops — technology that runs applications and full Windows desktops centrally in the data centre or cloud and streams only the screen to the user's device. This is the basis of Virtual Desktop Infrastructure (VDI) and published applications. Because the data and processing stay central and nothing meaningful is stored on the endpoint, Citrix has long been favoured in regulated industries, for remote and contractor access, and for delivering demanding applications to lightweight devices. The flagship product, Citrix Virtual Apps and Desktops (formerly XenApp/XenDesktop), is now also offered as a cloud-managed service, Citrix DaaS.

How It Works

Applications and desktops run on servers in the data centre or cloud. A user connects from the Citrix Workspace app on almost any device, authenticates, and is presented with their entitled apps and desktops. The session itself executes centrally; Citrix's HDX protocol transmits the display, keystrokes and mouse movements efficiently — tuned to stay usable even over constrained or high-latency networks. The endpoint effectively becomes a window onto a session running elsewhere, which is why even a thin client or tablet can run a heavy enterprise application.

Key Components

Component Role
Workspace app The client users run to reach their apps and desktops
Delivery Controller Brokers sessions and manages the environment
VDA (Virtual Delivery Agent) Installed on the machines that host sessions
StoreFront The portal listing a user's available resources
NetScaler / Citrix Gateway Secure remote access and load balancing at the edge

Common Use Cases

  • Remote and hybrid work — consistent access to corporate apps from anywhere.
  • Contractors and BYOD — deliver apps without trusting or managing the endpoint.
  • Regulated data — keep sensitive information in the data centre, never on the device.
  • Demanding or legacy apps — run graphics-heavy or hard-to-deploy software centrally.
  • Mergers and seasonal scale — provision and remove access quickly.

Security Considerations

Keeping data central is a security strength, but the access tier itself demands care. The internet-facing gateway and load-balancing appliances (NetScaler / Citrix Gateway) are high-value targets that have been subject to serious, actively exploited vulnerabilities. Treat them as critical infrastructure: patch promptly, restrict exposure, enable multi-factor authentication, and monitor closely. Session policies should also control clipboard, printing and drive mapping to prevent data leaving the controlled environment.

IT Director Considerations

  • Licensing and total cost of ownership, which can be significant and complex
  • Infrastructure complexity of on-premises VDI versus the cloud-managed DaaS model
  • End-user experience as the make-or-break factor for adoption
  • Security of the access tier, including prompt patching of gateway appliances
  • How Citrix relates to cloud alternatives such as Azure Virtual Desktop, Windows 365 and VMware Horizon — sometimes layered on top of them rather than replaced
  • Specialist skills required to design and operate the platform well

Citrix vs Cloud DaaS

Citrix is the established, feature-rich platform for app and desktop virtualisation, offering deep control and strong performance through HDX — at the cost of complexity and licensing. Native cloud DaaS offerings such as Azure Virtual Desktop and Windows 365 trade some of that depth for simplicity and a pure subscription model. The two are not mutually exclusive: Citrix is frequently deployed on top of cloud desktop services to add its management, optimisation and security capabilities. The decision usually comes down to required functionality, existing investment, and appetite for operating infrastructure.
