AZ-104: Azure Administrator Associate

Microsoft's role-based certification for managing Azure identities, storage, networking & compute

Overview

AZ-104 (Microsoft Azure Administrator Associate) is a role-based certification validating hands-on skills in managing Azure identities, governance, storage, virtual networks, and compute resources in production environments. In 2026, AZ-104 remains a standard baseline expectation for Azure administrator roles, typically pursued after AZ-900 and often a stepping stone toward more advanced or specialized Azure certifications (security, DevOps, solutions architecture).

Key Value: AZ-104 validates the practical, day-to-day administrative skills — resource management, monitoring, backup, networking configuration — that Azure environments depend on, giving hiring managers a reliable signal of hands-on operational competency.

Core Components

Exam Coverage

  • Azure identity & governance management
  • Storage, compute & virtual network implementation
  • Monitoring & backup configuration

Skills Validated

  • Resource group & subscription management
  • Azure AD/Entra ID user & group administration
  • Network security group & load balancer configuration

Certification Path

  • Builds on AZ-900 foundational knowledge
  • Common prerequisite for advanced Azure specializations
  • Recommended for hands-on Azure administrator roles

Best Practices

  • Pursue AZ-104 for staff in hands-on Azure administration roles
  • Combine certification study with real hands-on lab practice, not just theory
  • Use it as a baseline skill validation for Azure admin hiring & promotion
  • Plan continuing education as Azure services & the exam evolve
  • Pair with security-focused certifications for administrators handling sensitive environments

IT Director Responsibilities

  • Sponsor AZ-104 certification for Azure administrator staff
  • Use certification status to inform role readiness & hiring decisions
  • Track certification currency as Azure services evolve
  • Budget for hands-on lab access to support practical skill development
